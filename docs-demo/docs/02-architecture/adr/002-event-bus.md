# ADR-002：跨模块通信采用异步领域事件总线

- **状态**：已采纳（Accepted）
- **日期**：2026-10-12

## 背景

`Auth` 模块用户注册后，需要触发 `Billing` 初始化订阅、`Notification` 发送欢迎邮件。若采用同步 RPC 串联，会导致注册接口延迟升高且强耦合。

## 决策

跨业务域的非强一致性联动统一通过**异步领域事件（Event Bus）**完成，事件格式需预先登记在 `docs/04-contracts/events/`。

## 后果与约束

- **约束**：所有事件消费者必须实现**幂等性**（基于 `event_id` 去重）。
