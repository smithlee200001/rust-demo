# ADR-001：选择 PostgreSQL 作为主数据库

- **状态**：已采纳（Accepted）
- **日期**：2026-10-01

## 背景

系统需要存储多租户账单、订单与用户权限数据，对事务一致性和复杂关联查询有较高要求。

## 决策

选用 **PostgreSQL 16** 作为唯一主关系型数据库，并利用原生 JSONB 与 Row-Level Security（RLS）支持扩展字段和租户隔离。

## 后果与约束

- **正面**：强 ACID 保证，减少分布式事务复杂度。
- **约束**：所有表结构变更必须通过版本化迁移脚本管理，禁止手动在库中执行 DDL。
